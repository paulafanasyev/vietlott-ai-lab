# Улучшение статистической проверки — 6 ноября 2026

## Что изменено

Изменена только статистическая оценка в `worker/vlab/backtest.py`. Генераторы M0–M16, их параметры, исторические тиражи, ранее записанные live-билеты и прогнозы не менялись.

1. Для 16 неслучайных методов добавлена поправка Holm step-down. Она контролирует семейную вероятность ложного открытия и обычно менее консервативна, чем Bonferroni. Расчёт выполняется отдельно для среднего числа основных совпадений и для дополнительного числа Power.
2. Для каждого метода добавлен размер эффекта относительно математического ожидания случайного билета: `effect_vs_random`.
3. Добавлен 95%-й нормальный интервал для этого эффекта: `effect_ci95.lower/upper`.
4. Старые `p_value`, `p_value_bonferroni` и `verdict_vi` сохранены для сопоставления с прежними отчётами. Новые поля: `p_value_holm` и `verdict_holm_vi`; для Power аналогичные поля включены в `special_number`.

## Формулы и ограничения

Для одного билета число основных совпадений сравнивается с гипергеометрическим ожиданием:

- Mega 6/45: 0.8000 совпадения на билет.
- Power 6/55: 0.6545 совпадения на билет.

Дисперсия берётся из гипергеометрической модели. Доверительный интервал для разности среднего и случайного ожидания рассчитан как эффект ± 1.959964 × стандартная ошибка. Это нормальный интервал, а не bootstrap-интервал.

Holm: p-значения сортируются по возрастанию; для позиции i применяется множитель (m − i + 1), затем берётся накопительный максимум скорректированных значений. M0 — контрольная линия, поэтому в семью сравнений кандидатов не входит. Для Power основное число и дополнительное число образуют разные семейства гипотез.

Сохранённый `p_value` для основного числа остаётся двухсторонним z-тестом. Следовательно, улучшение повышает прозрачность учёта множественных сравнений, но не превращает его в точный тест и не доказывает предсказуемость лотереи.

## Критерий принятия

Изменение можно считать прошедшим только после CI: unit-тест Holm step-down, проверка интервалов эффекта и полный набор существующих worker-тестов. Даже зелёный CI подтверждает корректность реализации тестов, но не улучшение вероятности выигрыша. Новые алгоритмы или веса не продвигаются без отдельного результата на будущих, не использованных при настройке тиражах.
