# Vietlott AI Lab

Исследовательская система для Vietlott Mega 6/45 и Power 6/55: сбор результатов из источников, неизменяемая история, 17 методов прогнозирования, walk-forward-бэктест и сравнение со случайным выбором.

Интерфейс и отчёты — на вьетнамском языке; техническая документация — на русском.

> Лотерея случайна. Система не обещает выигрыш; её задача — измерять, а не угадывать.

## Структура

- `db/migrations/` — схема PostgreSQL. История только дописывается: UPDATE/DELETE/TRUNCATE запрещены триггерами; цепочка хешей обнаруживает подмену (`python -m vlab verify`).
- `worker/` — Python: сбор (`vlab/sources`), сверка (`vlab/reconcile.py`), запись (`vlab/store.py`), прогнозы (`vlab/live.py`), методы (`vlab/methods.py`), walk-forward (`vlab/backtest.py`), исследования (`vlab/research.py`).
- `.github/workflows/` — CI, ручная диагностика ingest и внешний backup.
- `docs/workflows/` — копии workflow для документации.

## Источники и статусы

| Источник | Роль |
|---|---|
| vietlott.vn (AjaxPro и официальные PDF) | официальный первоисточник; production сейчас получает HTTP 403 |
| pqminh-4/vietlott-data | архив результатов |
| vietvudanh/vietlott-data | дополнительный архив |
| NhanAZ-Data/vietlott-research | дополнительный архив |

- VERIFIED — официальный источник совпал хотя бы с одним независимым архивом.
- CROSS-CHECKED — совпали не менее двух независимых групп архивов.
- NOT PROVEN — подтверждение только одной группы происхождения.
- CONFLICT — источники расходятся; тираж исключается из расчётов.
- PENDING — ожидается публикация результата следующего тиража.

Нельзя считать CROSS-CHECKED эквивалентом официального VERIFIED. Конфликты и NOT PROVEN не включаются в backtest.

## Методы

- M0 — случайная контрольная линия.
- M1–M6 — частоты, интервалы, затухающая частота и пары.
- M7–M8 — ансамбль и адаптивные веса.
- M9 — онлайн-логистическая регрессия.
- M10 — структурно сбалансированный случайный билет.
- M11 — эвристика непопулярных комбинаций.
- M12 — покрытие набора билетов.
- M13 — двухсостоянийная модель Markov.
- M14 — Beta-Bernoulli Thompson sampling.
- M15 — индивидуальная модель интервалов.
- M16 — взвешенное голосование методов.

Каждый метод сравнивается с M0 и теоретическим гипергеометрическим baseline. M11 не повышает вероятность выигрыша; его гипотеза о меньшем делении джекпота не подтверждена данными продаж. M12 пока не доказал преимущества на уровне портфеля. M16 включает коррелирующие ансамбли M7/M8, поэтому его веса и дублирование сигналов требуют отдельного анализа.

## Запуск и секреты

Для production-инфраструктуры используются GitHub Actions Secrets:

1. `DATABASE_URL` — владелец БД, миграции и pg_dump.
2. `DATABASE_URL_WORKER` — роль `vlab_worker`, ограниченные операции записи.
3. `BACKUP_REPO` — `paulafanasyev/vietlott-ai-lab-backups`.
4. `BACKUP_REPO_TOKEN` — fine-grained token с Contents read/write только для приватного backup-репозитория.

Backup workflow теперь сначала проверяет наличие всех четырёх секретов и сообщает точное имя отсутствующего, не раскрывая значения.
